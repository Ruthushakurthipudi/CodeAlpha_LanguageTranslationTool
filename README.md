# 🌐 AI Language Translation Tool

An AI-powered Language Translation Tool developed using **Python, Streamlit, and an online translation API** as part of the **CodeAlpha Artificial Intelligence Internship**.

The application provides a simple and user-friendly interface for translating text between multiple languages.

---

## 🚀 Live Demo

### 🔗 Try the Application

👉 https://cyvefq.streamlit.app

The application is deployed using **Streamlit Community Cloud** and can be accessed directly from a web browser.

---

## 📌 Project Overview

Language barriers can make communication difficult between people who speak different languages.

The **AI Language Translation Tool** provides a web-based solution that allows users to enter text, select the source and target languages, and receive the translated text.

The application uses an online translation API to process the translation request.

---

## ✨ Features

- 🌍 Supports multiple languages
- 🔤 Source language selection
- 🌐 Target language selection
- 📝 Text input area
- 🔄 One-click translation
- ⚡ Online translation API integration
- ✅ Translation status messages
- 🖥️ Simple and interactive Streamlit interface
- 📱 Works on desktop and mobile browsers
- ☁️ Deployed online using Streamlit Community Cloud
